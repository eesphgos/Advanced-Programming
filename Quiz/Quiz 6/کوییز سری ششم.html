کوییز سری ششم
سامانه‌ای طراحی کنید که بتواند گزارش‌هایی با انواع مختلف تولید کند. برخی گزارش‌ها باید **قابلیت لاگ‌کردن زمان تولید** را داشته باشند. الزامات دقیق پیاده‌سازی: 1. یک **enum** به نام `ReportType` با مقادیر `Daily`, `Monthly` تعریف کنید. 2. یک **interface** به نام `IReport` طراحی کنید که شامل property فقط خواندنی زیر باشد: + `ReportType Type { get; }` + یک متد `void Generate()` برای تولید گزارش. 3. یک **interface** دیگر به نام `ILoggedReport` طراحی کنید که از `IReport` ارث ببرد و شامل متد: + `void LogGenerationTime();` باشد. این متد باید زمان اجرای تولید گزارش را ثبت کرده و در کنسول چاپ کند. 4. یک کلاس `ReportBase` به صورت `abstract` طراحی کنید که: + واسط `IReport` را پیاده‌سازی کند. + متد `Generate()` را به صورت `virtual` پیاده‌سازی کند. + متد `LogGenerationTime()` را به صورت `abstract` باقی بگذارد. 5. دو کلاس `DailyReport` و `MonthlyReport` ایجاد کنید که از `ReportBase` ارث ببرند: + هر دو کلاس باید `ILoggedReport` را پیاده‌سازی کنند. + کلاس `MonthlyReport` باید متد `Generate()` را بازنویسی کند و آن را `sealed` کند. + در متد `LogGenerationTime()` برای هر کلاس، زمان جاری را با پیام مناسب و نوع گزارش چاپ کنید (مثلاً: `Generated Monthly Report at 2025-05-14 12:34:56`). 6. در `Main`، لیستی از `IReport` ایجاد کنید که شامل `DailyReport` و `MonthlyReport` باشد. + برای هر گزارش، ابتدا متد `Generate()` را اجرا کنید. + اگر گزارش از نوع `ILoggedReport` بود، متد `LogGenerationTime()` را نیز اجرا کرده و زمان را چاپ کنید. + برای دریافت زمان حاضر می‌توانید از DateTime.Now استفاده کنید.

طراحی سامانه گزارش‌گیری قابل لاگ‌گیری


سامانه‌ای طراحی کنید که بتواند گزارش‌هایی با انواع مختلف تولید کند. برخی گزارش‌ها باید قابلیت لاگ‌کردن زمان تولید را داشته باشند.

الزامات دقیق پیاده‌سازی:

  1. یک enum به نام ReportType با مقادیر Daily, Monthly تعریف کنید.

  2. یک interface به نام IReport طراحی کنید که شامل property فقط خواندنی زیر باشد:

    • ReportType Type { get; }

    • یک متد void Generate() برای تولید گزارش.

  3. یک interface دیگر به نام ILoggedReport طراحی کنید که از IReport ارث ببرد و شامل متد:

    • void LogGenerationTime(); باشد. این متد باید زمان اجرای تولید گزارش را ثبت کرده و در کنسول چاپ کند.

  4. یک کلاس ReportBase به صورت abstract طراحی کنید که:

    • واسط IReport را پیاده‌سازی کند.

    • متد Generate() را به صورت virtual پیاده‌سازی کند.

    • متد LogGenerationTime() را به صورت abstract باقی بگذارد.

  5. دو کلاس DailyReport و MonthlyReport ایجاد کنید که از ReportBase ارث ببرند:

    • هر دو کلاس باید ILoggedReport را پیاده‌سازی کنند.

    • کلاس MonthlyReport باید متد Generate() را بازنویسی کند و آن را sealed کند.

    • در متد LogGenerationTime() برای هر کلاس، زمان جاری را با پیام مناسب و نوع گزارش چاپ کنید (مثلاً: Generated Monthly Report at 2025-05-14 12:34:56).

  6. در Main، لیستی از IReport ایجاد کنید که شامل DailyReport و MonthlyReport باشد.

    • برای هر گزارش، ابتدا متد Generate() را اجرا کنید.

    • اگر گزارش از نوع ILoggedReport بود، متد LogGenerationTime() را نیز اجرا کرده و زمان را چاپ کنید.

    • برای دریافت زمان حاضر می‌توانید از DateTime.Now استفاده کنید.

ساختاری طراحی کنید که امکان نگهداری و چاپ اطلاعات موجودیت‌هایی که هم قابل شناسایی (دارای شناسه یکتا و نوع) و هم قابل پیگیری زمانی (تاریخ ایجاد) هستند را فراهم کند. ### الزامات: 1. **واسط‌ها (Interfaces):** + یک **واسط به نام `IIdentifiable`** تعریف کنید که دارای دو property فقط خواندنی زیر باشد: + `Id` از نوع `Guid` – نشان‌دهنده شناسه یکتای موجودیت + `TypeName` از نوع `string` – نشان‌دهنده نوع موجودیت به صورت متن + یک **واسط دیگر به نام `IAuditable`** تعریف کنید که از `IIdentifiable` ارث‌بری کند و دارای یک property فقط خواندنی به نام زیر باشد: + `CreatedAt` از نوع `DateTime` – نشان‌دهنده زمان ایجاد موجودیت 2. **کلاس انتزاعی (Abstract Class):** + یک کلاس انتزاعی به نام `EntityBase` تعریف کنید که واسط `IAuditable` را پیاده‌سازی کند. + این کلاس باید در **سازنده (Constructor)** خود: + مقدار `Id` را با یک مقدار جدید از `Guid.NewGuid()` مقداردهی کند. + مقدار `CreatedAt` را با `DateTime.Now` مقداردهی کند. + property `TypeName` باید به صورت `abstract` باقی بماند تا کلاس‌های فرزند مقدار مناسب را برای آن تعریف کنند. 3. **کلاس‌های فرزند:** + دو کلاس به نام‌های `Person` و `Company` تعریف کنید که از `EntityBase` ارث‌بری کنند. + این کلاس‌ها باید property `TypeName` را override کرده و مقدار آن را به ترتیب برابر با `"Person"` و `"Company"` قرار دهند. 4. **کلاس چاپ موجودیت‌ها:** + یک کلاس ایستا (static) به نام `EntityPrinter` تعریف کنید که دارای یک متد ایستا (static method) به نام `PrintInfo` باشد. + این متد باید یک پارامتر از نوع `IAuditable` دریافت کند و مقادیر `Id`، `TypeName` و `CreatedAt` را در کنسول چاپ کند. + بین اطلاعات چاپ‌شده برای هر موجودیت، یک خط افقی از کاراکتر `-` نمایش داده شود (برای خوانایی بهتر). 5. **در متد `Main`:** + یک نمونه از کلاس `Person` و یک نمونه از کلاس `Company` بسازید. + متد `PrintInfo` را برای هر کدام فراخوانی کرده و خروجی را در کنسول چاپ کنید.

طراحی ساختار موجودیت‌های قابل شناسایی و پیگیری زمانی

الزامات:🔗

  1. واسط‌ها (Interfaces):

    • یک واسط به نام IIdentifiable تعریف کنید که دارای دو property فقط خواندنی زیر باشد:
